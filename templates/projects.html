SmartDoc – Intelligent Document Understanding Platform

An AI-powered web application that enables users to upload PDF documents and interact with them using natural language questions. Instead of manually reading lengthy documents, users can ask questions and get accurate answers based on the uploaded PDF. Text is extracted using PyPDF, user queries are processed with the Google Gemini API, and responses are displayed through a clean, responsive Flask-based web interface.

How it works:

  1. User uploads a PDF document.
  2. SmartDoc extracts the text from the PDF.
  3. The user enters a question about the document.
  4. The extracted text and question are sent to the Gemini AI model.
  5. The AI generates an answer based on the uploaded document.
  6. The response is displayed on the webpage.
